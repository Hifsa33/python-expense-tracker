python-expense-tracker.py 💰

A desktop application built with Python to manage personal income and expenses through a graphical user interface.

 Features

- Dashboard showing monthly income, expenses, balance, and budget remaining
- Add, update, and delete transactions
- Categorize income and expenses
- Search and filter transactions
- Set a monthly budget
- Export transactions to CSV
- Automatically save data using SQLite
- Light and dark themes

Technologies Used

- Python 3
- Tkinter
- SQLite
- CSV

 Requirements

- Python 3 with Tkinter available
- No external Python packages required

 How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the command:

```bash
python main.py
```

The SQLite database will be created automatically when the application starts.

 Project Structure

```text
python-expense-tracker/
├── python-expense-tracker.py

```

**Note:** `expense_tracker.db` is generated automatically when the program runs.
